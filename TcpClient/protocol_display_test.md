## 技术实现

### 数据存储
- **显示文本**: `A:读取软件版本` (用户看到的)
- **数据值**: `A` (实际的功能代码)
- **提取逻辑**: 通过 `currentData()` 获取或从显示文本中分割

### 兼容性处理
```cpp
QString functionCode = ui->comboBox_function_code_frame->currentData().toString();
if (functionCode.isEmpty()) {
    QString display = ui->comboBox_function_code_frame->currentText();
    functionCode = display.split(':').first();
}
```

## 用户体验

### 优势
- ✅ **简洁明了**: 冒号分隔，格式统一
- ✅ **信息完整**: 代码和功能名称都显示
- ✅ **易于查找**: 按功能代码字母排序
- ✅ **节省空间**: 比破折号格式更紧凑

# TCP 客户端测试指南

## 测试步骤

### 1. 启动应用程序
- 运行编译好的应用程序
- 点击菜单 "设置" -> "TCP调试"
- 应该会打开TCP通信调试工具窗口

### 2. 测试服务端模式
1. 选择"服务端模式"
2. 设置端口为8080
3. 点击"连接"按钮
4. 应该看到"服务端启动成功，监听端口: 8080"的消息

### 3. 测试客户端模式
1. 打开另一个TCP调试窗口（或使用其他TCP客户端工具）
2. 选择"客户端模式"
3. 设置远端IP为127.0.0.1，端口为8080
4. 点击"连接"按钮
5. 应该看到"已连接到服务器"的消息

### 4. 测试消息收发
1. 在客户端窗口的发送框中输入"Hello Server"
2. 点击"发送"按钮
3. 在服务端窗口应该看到接收到的消息
4. 在服务端窗口输入"Hello Client"
5. 点击"发送"按钮
6. 在客户端窗口应该看到接收到的消息

### 5. 测试十六进制模式
1. 勾选"十六进制模式"
2. 在发送框中输入"48 65 6C 6C 6F"（Hello的十六进制）
3. 点击"发送"按钮
4. 接收方应该看到十六进制格式的消息

## 预期结果

- 界面应该美观且功能完整
- 连接状态应该正确显示
- 消息收发应该正常工作
- 时间戳和自动滚动功能应该正常
- 多客户端连接应该支持
- 错误处理应该友好

## 故障排除

如果遇到问题：
1. 检查防火墙设置
2. 确认端口没有被其他程序占用
3. 检查IP地址配置是否正确
4. 查看控制台输出的调试信息

# 帧结构编辑器使用指南

## 🎯 功能概述

帧结构编辑器提供了逐字段编辑协议帧的功能，完全按照通信帧格式设计：

```
序号: 1      2        3       4        5        6
字段: 帧头   从机地址  功能代码  命令数据  校验和   帧尾
格式: 0x3E   2字符    1字符    N字符    4字符    0x0D0A
```

## 📋 字段详解

### 1. 帧头 (0x3E)
- **选项**: `3E` (十六进制) 或 `>` (ASCII字符)
- **长度**: 1字符
- **说明**: 协议帧的起始标识符

### 2. 从机地址 (2字符)
- **ADP1000**: 01-08 (8个设备)
- **CStep**: 01-32 (32个设备)
- **格式**: 两位数字，不足补0

### 3. 功能代码 (1字符)
- **动态加载**: 根据选择的协议类型自动加载
- **ADP1000**: A-z, 0-9, +, -, S, s 等46个指令
- **CStep**: A-z, 0-9, +, -, *, / 等34个指令

### 4. 命令数据 (N字符)
- **可选字段**: 根据功能代码决定是否需要
- **格式**: ASCII字符 '0'-'9', 'A'-'Z', 'a'-'z'
- **长度**: 可变，根据具体指令而定

### 5. 校验和 (4字符)
- **自动计算**: 使用CRC-16-ModBus算法
- **只读显示**: 用户无需手动输入
- **实时更新**: 任何字段变化都会重新计算

### 6. 帧尾 (2字符)
- **选项**: `0D0A` (十六进制) 或 `\r\n` (ASCII)
- **标准**: 0x0D + 0x0A (回车换行)

## 🔧 操作方式

### 实时构建模式 (推荐)
1. ☑ 勾选"实时构建"
2. 选择任意字段 → `textEdit_frame_preview` 立即更新
3. 修改任意内容 → 预览实时刷新
4. 校验和自动计算 → 无需手动操作

### 手动构建模式
1. ☐ 取消"实时构建"
2. 设置所有字段
3. 点击"构建帧" → `textEdit_frame_preview` 显示结果

## 🎨 显示效果

### ASCII模式显示
```
textEdit_frame_preview 内容:
>01A63D8
```

### 十六进制模式显示  
```
textEdit_frame_preview 内容:
3E 30 31 41 36 33 44 38 0D 0A
```

## 🚀 快捷操作

### 智能填充
- **作用**: 从上方协议配置一键同步到帧编辑器
- **使用**: 先在协议配置中选择，再点击"智能填充"
- **效果**: 自动设置从机地址、功能代码、命令数据

### 构建帧
- **作用**: 手动触发帧构建
- **效果**: 立即更新 `textEdit_frame_preview` 和发送框

### 重置
- **作用**: 清空所有字段到默认状态
- **效果**: 帧头=3E, 地址=01, 功能码=第一个, 数据=空, 帧尾=0D0A

## 💡 实时显示特性

### 触发条件
任何以下操作都会触发 `textEdit_frame_preview` 更新：

1. **字段变化**:
   - 选择不同的帧头
   - 选择不同的从机地址
   - 选择不同的功能代码
   - 输入或修改命令数据
   - 选择不同的帧尾

2. **显示模式变化**:
   - 切换十六进制显示模式
   - 切换实时构建模式

3. **手动操作**:
   - 点击"构建帧"按钮
   - 点击"智能填充"按钮

### 更新内容
`textEdit_frame_preview` 会显示：
- **完整协议帧**: 包含所有字段的完整帧
- **正确格式**: 根据选择的显示模式格式化
- **实时校验**: CRC校验和实时计算并包含在帧中

## 🔄 与发送框同步

当帧构建完成时：
- `textEdit_frame_preview` 显示格式化的帧（用于预览）
- `lineEdit_send` 自动填充原始帧数据（用于发送）
- 用户可以直接点击"发送"按钮发送协议帧

这样确保了 `textEdit_frame_preview` 始终显示最新构建的帧数据！

# TCP 通信调试工具使用说明

## 功能概述

这是一个功能完整的TCP客户端/服务端调试工具，支持：

- **双模式运行**：客户端模式和服务端模式
- **实时通信**：支持文本和十六进制数据传输
- **多客户端支持**：服务端模式可同时连接多个客户端
- **消息记录**：完整的收发消息历史记录
- **状态监控**：实时显示连接状态和连接信息

## 界面说明

### 1. 工作模式选择
- **客户端模式**：连接到远程服务器
- **服务端模式**：监听端口，等待客户端连接

### 2. 网络配置
- **本机IP**：当前机器的IP地址（服务端模式时使用）
- **本机端口**：服务端监听的端口号
- **远端IP**：要连接的服务器IP地址（客户端模式时使用）
- **远端端口**：要连接的服务器端口号

### 3. 连接控制
- **连接按钮**：启动服务端或连接到服务器
- **断开按钮**：关闭服务端或断开连接
- **清空按钮**：清空消息显示区域
- **状态显示**：显示当前连接状态

### 4. 消息收发
- **接收区域**：显示接收到的消息（只读）
- **发送输入框**：输入要发送的消息
- **发送按钮**：发送消息
- **选项设置**：
  - 自动滚动：新消息自动滚动到底部
  - 显示时间戳：每条消息前显示时间
  - 十六进制模式：以十六进制格式发送/接收数据

## 使用方法

### 作为服务端使用

1. 选择"服务端模式"
2. 设置本机端口（如8080）
3. 点击"连接"按钮启动服务端
4. 等待客户端连接
5. 在发送框中输入消息，点击"发送"发送给所有连接的客户端

### 作为客户端使用

1. 选择"客户端模式"
2. 输入服务器IP地址和端口
3. 点击"连接"按钮连接到服务器
4. 在发送框中输入消息，点击"发送"发送给服务器

## 高级功能

### 十六进制模式
- 勾选"十六进制模式"后，可以发送十六进制数据
- 输入格式：`48 65 6C 6C 6F`（Hello的十六进制）
- 接收到的数据也会以十六进制格式显示

### 多客户端支持
- 服务端模式支持同时连接多个客户端
- 发送消息时会广播给所有连接的客户端
- 连接信息区域显示当前连接的客户端数量

### 消息类型颜色
- **错误消息**：红色
- **成功消息**：绿色
- **警告消息**：黄色
- **发送消息**：蓝色
- **接收消息**：紫色
- **普通信息**：灰色

## 技术特性

- 基于Qt网络模块实现
- 支持IPv4网络通信
- 异步非阻塞网络操作
- 完整的错误处理机制
- 实时状态更新
- 内存安全的资源管理

## 注意事项

1. 确保防火墙允许指定端口的通信
2. 服务端和客户端端口不能冲突
3. 十六进制模式下输入必须是有效的十六进制字符
4. 长时间运行建议定期清空消息记录以节省内存
